# Readmint template test

The Readmint profile templates, rendered by the [Readmint Action](https://github.com/MrLarkyy/Readmint) `v0.3.0`
with live data of MrLarkyy. The workflow in `.github/workflows/readmint.yml` renders every section daily and on demand
and commits the SVGs; light and dark follow your GitHub theme.

- [Year Ring](year-ring/README.md)
- [Horizon](horizon/README.md)
- [Pinscreen](pinscreen/README.md)

Each template folder holds its designs (the template files) and the personal texts in `designs/settings.json`, set with the Action input
`props-file`, and the rendered output in `readmint/`. To use one, copy its `designs/` folder and its job step into your profile repository.

The `designs/` folders and the READMEs are generated by `readmint-examples` from `packages/components/templates/profiles`
in [MrLarkyy/Readmint](https://github.com/MrLarkyy/Readmint) and must not be edited by hand.

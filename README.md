# Readmint template test

The three Readmint profile templates, rendered by the [Readmint Action](https://github.com/MrLarkyy/Readmint) `v0.1.0`
with live data of MrLarkyy. The workflow in `.github/workflows/readmint.yml` renders every section daily and on demand
and commits the SVGs; light and dark follow your GitHub theme.

- [Year Ring](year-ring/README.md)
- [Horizon](horizon/README.md)
- [Pinscreen](pinscreen/README.md)

Each template folder holds its designs (with the personal texts filled in) in `designs/` and the rendered output in
`readmint/`. To use one, copy its `designs/` folder and its job step into your profile repository.
